# Chordex v2 — Retro-Brutalist Redesign + Chord Sheet + Multi-language Lyrics

## Design direction (senior-designer rationale)
Your asset kit is a coherent **neubrutalist + retro-pixel** system: pixel-art logo with purple→teal→orange gradient guitar on black, 256 hard-shadow icons, 10 dotted halftone textures, RetroByte 8-bit font, CS Claire Mono. Glassmorphism/neumorphism would fight this kit. So: **"Retro-brutalist studio"** — near-black canvas with halftone texture, thick 2px borders + hard offset shadows on interactive components, vivid flat colors, pixel font for chord names/numerals (echoes the logo), mono font for lyrics/timestamps, and *restrained* glass (backdrop blur) only on ambient/sticky surfaces. Distinctive, cohesive, zero generic-AI-slop.

Palette from the logo: ink `#0A0A0F`, paper `#F5F0E8`, violet `#7C5CFF`, teal `#2DD4BF`, amber `#FFB020`; chord-type language: major=violet, minor=teal, extension=amber, N=gray; active highlight = paper/amber.

## Part 4 — Lyrics quality + Hindi/Malayalam (backend)

**`backend/lyrics_transcriber.py`**:
- Decode params: `beam_size=5`, `condition_on_previous_text=False`, `hallucination_silence_threshold=2.0`, `vad_parameters={"min_silence_duration_ms": 1000, "speech_pad_ms": 200}` (music-tuned), `word_timestamps=True`, `language` passed when provided (else `WHISPER_LANGUAGE` env, else auto).
- **Per-language model map**: default `WHISPER_MODEL=small` for English/Hindi/auto; **Malayalam → `medium`** (low-resource language; small is weak there). Map lives in one dict, overridable via `WHISPER_MODEL_OVERRIDES` env (JSON). Model cache keyed by name. First Malayalam run downloads `medium` (~1.5 GB, one-time) — surfaced in UI copy.
- **Rebuild `lyric_lines` from word timestamps with gap-based grouping** (replaces raw Whisper segments as lines).

**`backend/main.py` + `worker.py`**: optional `language` form field on `/api/analyze` → stored with job → threaded to `transcribe_lyrics`. Bump `job_timeout` to 900s for medium-model runs. `.env.example` documents new vars.
